# Intrareg para Claude

Plugin de Intrareg para Claude Code y Cowork: calificación registral con el Catálogo de defectos y la doctrina de la Dirección General
de Seguridad Jurídica y Fe Pública, y la nota de calificación como borrador en Intrareg. No lleva datos: todo se consulta en vivo por el
conector de Intrareg con la cuenta del registrador.

```
/plugin marketplace add jgomeza88/intrareg-plugin
/plugin install intrareg@intrareg
```

Para que se ponga al día solo: `/plugin` › Marketplaces › intrareg › «Enable auto-update» (una vez). Sin eso, `/plugin marketplace
update intrareg` trae la versión nueva.

Detalle de lo que trae y de la privacidad: [plugins/intrareg/README.md](plugins/intrareg/README.md).
